# Professional workspace identity — concept stage

Name remains open: user rejected Alur, Orbit, Rencana, Kendali, Aruna, Forma, and Strata. Do not rename live UI until an accepted name exists. Audience: project managers, project members, management. Tone: professional, clear, dependable, calm. Uses: sidebar, login, favicon, professional reports. Black-first geometry; native SVG; warm paper UI with blue action accent. No mascot, gradients, shields, checkmarks, task-list clip art, or stock initial.

## Exploration

1. Shared corner — two interlocking orthogonal pieces sharing an open centre (abstract modular).
2. Fold — one folded ribbon with a deliberate break between planes (pictorial).
3. Aperture — a compact solid enclosure with an off-centre stepped opening (emblem/negative space).
4. Relay — a capsule route with separated endpoints (rejected: generic circuit).
5. Pivot — asymmetric paired arcs (rejected: poor small-size clarity).
6. Register — repeated inset bars (rejected: Linear-like category convention).
7. Guideline — two unequal brackets (rejected: code-tool association).
8. Facet — three parallel planes (rejected: generic layered stack).
9. Initial — a custom letter tied to brand name (deferred until name is approved).

Selected concepts 1–3 maximize small-size readability with different constructions. Research: local productivity-collaboration catalog; studied Vercel primitive discipline, Kotlin angular construction, Patreon form-weight balance, Framer junctions. No source geometry copied.

## Construction and refinement

256-square canvas. Large 40px positive/negative features. Orthogonal primitives for A/C; symmetric two-plane silhouette for B. v1 retains first construction; v2 corrects footprint, narrows widths and aligns negative gaps for size 16. Concept labels describe directions, not the product name. These are exploratory symbols, not a finished identity or cleared trademark.
